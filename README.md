# BathPass

BathPass is a credit-based membership that gives you access to top bathhouses, saunas, and recovery spaces across the city — one membership, multiple venues, book with credits, go with friends.

## Current state

- Static single-page prototype in `index.html`
- Includes city tabs, map integration (Leaflet), filters, and venue cards
- Venue data is embedded in the page script

## Run locally

Open `index.html` in a browser. The map uses external Leaflet assets and needs internet access to render.
